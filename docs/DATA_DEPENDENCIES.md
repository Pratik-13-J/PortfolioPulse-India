# External Data Dependencies

These inputs are **not** in the project and are never fabricated. Each feature below stays gated, unavailable or labelled illustrative until you supply the data. Every file needs a JSON sidecar declaring its source and SHA-256 (`reference_data.read_sidecar`). Back up the database before each import.

| # | Data | Unlocks | Current behaviour | How to supply |
|---|---|---|---|---|
| 1 | **NSE Corporate Actions CSV**: RELIANCE, HDFCBANK, INFY, ICICIBANK, ITC; 2024-01-01 → 2026-10-16 (nseindia.com → Companies Listing → Corporate Filings → Corporate Actions) | Confirms dataset 1's price basis; creates a corrected **new** dataset version (Dataset 3). Dataset 1 is never modified | Dataset 1 is labelled `unadjusted_ohlcv`; the evidence suggests split/bonus-adjusted prices | `python -m scripts.corporate_actions convert --dataset-id 1 --raw <nse.csv> --out <ca.csv> --source-url <url> --retrieved-at <ISO time>`, then `import --csv <ca.csv>`, `evidence ...`, then `build-version ...` after your decisions |
| 2 | **ITC Hotels demerger valuation**: ITC's cost-of-acquisition split, or NSE's ex-date adjusted price | A demerger price adjustment, which also needs a new price-basis label (a future schema migration) | The demerger stays unadjusted and flagged `requires_value_source` | Provide the official document; the adjustment factor will be derived from it, never estimated |
| 3 | **NIFTY 50 constituent weights** with NSE industry classifications (official, or explicitly labelled estimated) | Real Brinson-Fachler attribution and Active Share | Gated; the dashboard shows a *synthetic, labelled* demonstration only | CSV columns `symbol, company_name, industry, weight`. The sidecar adds `benchmark_symbol`, `as_of_date` and `weight_basis` (`official`/`estimated`). Import with `reference_data.import_benchmark_constituents`, plus `save_security_classifications` |
| 4 | **RBI/FBIL 10-year G-sec yield** and **USD/INR (FBIL reference rate)** daily series | Rate/FX sensitivities estimated by OLS, with standard errors | Illustrative **assumed** sector sensitivities (`config/stress_scenarios.json`), labelled in the dashboard | CSV `date (YYYY-MM-DD), india_10y_yield_pct, usdinr` with a sidecar; run `python -m scripts.analyze_stress --dataset-id 1 --macro-factor-csv <file>` |
| 5 | **NIFTY 50 price-index history for 2020 and 2022** (NSE Indices historical data) | COVID-2020 and 2022 inflation/rate-shock scenarios (model-propagated, β × index move) | Reported **unavailable**; dataset 1 starts 2024-01-02 | `python -m scripts.analyze_stress --dataset-id 1 --nse-reference-csv <file>` |

Running a stress or optimization script with new inputs creates a **new** stored run, because the settings differ; it never overwrites runs 9–11. Re-run the dashboard afterwards to see it.
